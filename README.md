Single-page English site. Replace the four portrait placeholders only after receiving consented images.

## Image filenames

* `assets/people/venkateshwarlu.jpg`
* `assets/people/varalaxmi.jpg`
* `assets/people/chaitanya.jpg`
* `assets/people/siri.jpg`

Recommended: square JPG or WebP, 800×800 or larger, under 300 KB each. Do not commit Aadhaar, PAN, signatures, or private documents.

## Publish

Set GitHub Pages to deploy from the branch/folder containing this `index.html`. Use the repository's Pages URL for testing before changing DNS.

## Wix domain

Keep Wix only as the domain/DNS registrar if desired. Do not connect the domain to Wix hosting and GitHub Pages at the same time. After GitHub Pages is working, add the Pages-provided custom-domain CNAME/records in Wix DNS, then enable HTTPS in GitHub Pages. DNS changes can take time to propagate.
